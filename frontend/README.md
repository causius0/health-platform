# Health Platform — frontend

React 18 SPA (Vite, react-router, chart.js). Talks to the Flask backend under `/api`.

```bash
npm install
npm run dev      # Vite dev server on :5173, proxies /api → 127.0.0.1:5001
npm run build    # production build in dist/
npm test         # vitest
npm run lint     # eslint
```
